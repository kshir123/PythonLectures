## 🚀 Getting Started

### Prerequisites
- Python 3.14+
- pip

### Clone the Repository
```bash
git clone https://github.com/kshir123/PythonLectures.git
cd PythonLectures
```

### Run any chapter file
```bash
python PythonHarry/CHAPTER-2/variable.py
```

### Setup for CHAPTER-13 (Flask & FastAPI)
```bash
cd PythonHarry/CHAPTER-13
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```
